## PR-2026-10-03-02 — File Sheets mẫu: key có sẵn, ngày lỗi, tab thô, biểu đồ xấu
**Yêu cầu (rút gọn trung thực, user rất bực):** (1) "file refresh mẫu tại sao
lại có sẵn token?", "tại sao ngày cứ bị lỗi hoài, qua bao nhiêu session một lỗi
vẫn cứ ở đó"; (2) "dữ liệu thô là cái gì, khách cần à?", cột `c1 c2` không rõ
nghĩa; (3) so biểu đồ trong file với dashboard Excel/Sheets ngoài thị trường.

**Kết quả:** `integrations/google-sheets/build_template.py` viết lại:
- Ngày ra khỏi công thức dưới dạng chữ (`TEXT`), không phụ thuộc định dạng ô.
- `FILTER` thay `QUERY` → **phát hiện kèm**: tab GDP trên file mẫu đang mất
  toàn bộ cột "Khu vực" (QUERY ép kiểu theo số đông).
- Ô "Dữ liệu mới nhất" trên file mẫu luôn "—" dù có dữ liệu → bỏ `SORT`.
- Tab thô đổi tên `_raw` và **ẩn**; khoảng thời gian chọn ở `C8` trang bìa.
- Tab mới **"Tổng quan"**: 8 thẻ KPI (giá trị mới nhất, thay đổi so kỳ trước có
  màu ▲/▼, sparkline 90 điểm, ngày kỳ), 7 biểu đồ (vàng, tỷ giá, lãi suất LNH,
  vàng TG, CPI, XNK, GDP toàn nền KT). Bỏ các cột API luôn rỗng (tỷ giá mua/bán,
  GDP tỷ VND).
- `tests/sheets/test_build_template.py`: 30 test.

**Về token:** đọc file mẫu gốc qua Drive → **ô C6 đang chứa một API key thật**,
file share "anyone with link". Mọi bản copy nhận key đó và tiêu quota của chủ
key. Đây là lần thứ hai (lần đầu 2026-09-29). Bản build luôn để C6 trống; key
chỉ có thể vào đó do ai đó dán tay vào file gốc.

**Không làm, có lý do:**
- **Chưa kiểm trên Google Sheets thật.** Đây đúng là lý do lỗi ngày sống qua
  nhiều phiên. Chrome extension không có quyền trên `docs.google.com`; Drive
  connector từ chối chuyển xlsx ("Invalid conversion requested"). Chưa thay file
  gốc — việc import "Replace spreadsheet" là của chủ file, kèm checklist trong
  README "Verifying a rebuild".
- **Không tự xoay (rotate) key bị lộ:** thao tác trên tài khoản user, user tự
  làm ở developer.html.
- Biểu đồ trong file là chart của Sheets (convert từ xlsx), không đạt mức
  dashboard thiết kế như ảnh mẫu; muốn tới mức đó phải dựng bằng Looker
  Studio hoặc thiết kế tay trong Sheets.

**Sự cố trong phiên:** agent kia lại xoá panel `#dataset-tools` và chèn đoạn
"Chart detail cleanup" vào `CLAUDE.md` lần thứ hai **sau khi** user đã chọn
giữ panel. Đã đưa 3 file FE về bản commit `883093c03` và xoá đoạn đó.
