Google Sheets

Copy một file về Drive của bạn, dán API key vào một ô, và có ngay chín bộ dữ liệu kinh tế Việt Nam tự cập nhật. Không cài đặt gì, không cấp quyền gì.

File mẫu — chỉ 2 bước

Tạo bản sao file mẫu →

Mở bằng tài khoản Google của bạn. File sao chép nằm trong Drive của bạn.

  1. Nhấn “Tạo bản sao”. Google mở hộp thoại xác nhận, bấm nút là xong. Bản sao là của bạn, sửa thoải mái.
  2. Dán API key vào ô C4 của tab “Bắt đầu”. Chín tab dữ liệu tự đổ về ngay.
Không có bước ba. File mẫu dùng hàm IMPORTDATA có sẵn của Google Sheets, nên không có tiện ích bổ sung nào được cài, không có màn hình xin cấp quyền, không có cảnh báo “Google chưa xác minh ứng dụng này”.

Lấy API key

Đăng nhập Viet Dataverse rồi mở trang Developer để tạo key. Tài khoản miễn phí được cấp key ngay.

Đăng nhập · Mở trang Developer

Key nằm trong ô C4 của bản sao của bạn, nên ai xem được file thì xem được key. Đừng chia sẻ file cho người lạ. Nếu lỡ lộ, vào trang Developer tạo key mới — key cũ mất hiệu lực ngay.

Dữ liệu cập nhật khi nào

Google tự gọi lại dữ liệu khi bạn mở file, và khoảng một giờ một lần trong lúc file đang mở. Bạn không phải bấm gì cả.

Muốn ép cập nhật ngay: tải lại trang (F5). Nếu cần một giá trị đứng yên để đối chiếu, copy vùng dữ liệu rồi Dán đặc biệt → Chỉ dán giá trị sang tab khác.

Hạn mức

Mỗi tab là một lượt gọi API. Mở file một lần với đủ chín tab là chín lượt.

GóiHạn mứcThực tế với file này
Miễn phí2 request/thángKhông đủ để đổ hết chín tab dù chỉ một lần — chỉ nên dùng để thử một tab
API Supper Lite1.000 request/thángKhoảng 110 lần mở file mỗi tháng

Dùng ít tab thì tốn ít lượt hơn: xoá công thức ở ô A1 của những tab bạn không cần, chúng sẽ ngừng gọi API.

Tự viết công thức (không dùng file mẫu)

Nếu bạn chỉ cần đúng một bộ dữ liệu trong bảng tính sẵn có, không cần copy file mẫu. Dán key vào một ô — ví dụ B1 — rồi dùng:

=IMPORTDATA("https://api.vietdataverse.online/api/v1/gold?type=SJC&period=1y&format=csv&api_key="&$B$1)

Tham chiếu ô $B$1 thay vì gõ thẳng key vào công thức: đổi key một chỗ là mọi công thức đổi theo.
